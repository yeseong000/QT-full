## 현재 프롬프트의 구조적 빈칸

- `03_question_rules.md`에 **카테고리별 정의·예시가 없습니다.** 104~110행은 라벨 9개 나열뿐.
- 위쪽 '질문 각도' 7개와 카테고리 9개가 짝이 안 맞아 `주석형/본문관찰`·`랜덤`은 설명이 아예 없음.
- KB `key_details`에는 사실마다 `cat`(본문관찰·신학핵심·문화관습·지리·어원·인물배경)이 붙어 있고
  질문 카테고리와 1:1로 맞는데, **프롬프트가 이 연결을 한 번도 말해주지 않습니다.**
